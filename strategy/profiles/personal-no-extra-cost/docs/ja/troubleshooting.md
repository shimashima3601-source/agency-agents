# 停止・エラー時の説明

| 表示・状況 | 意味と対応 |
|---|---|
| 未知のプロファイル・設定 | 対応するprofileを確認。無制限モードへ戻らない |
| 課金禁止または未確認の操作 | 操作を実行せず、公開資料・手動利用等を検討 |
| API認証設定を検出 | 値を表示せず停止。実行環境と認証経路を確認 |
| 当日の実行前確認がない | UIで確認し記録。未確認項目をtrueにしない |
| Agent参照切れ・辞書不一致 | Upstreamの追加・削除・改名を確認して更新 |
| UpstreamのCodex形式が変化 | アダプターをレビューし、元の形式を勝手に変更しない |
| 生成物が編集されている | 編集を別資料に保存。管理ファイルを改ざんして突破しない |
| 配置先の同名ファイルと衝突 | 別プロジェクト等を選択。管理外ファイルを削除しない |
| シンボリックリンク | 実ディレクトリを選択。リンク先のファイルへ書き込まない |
| CloudでAgentを認識しない | 読込未対応として記録し、元Markdownの役割を順次適用 |
| Plus等の利用上限 | 進捗・根拠・未完了作業を保存。上限リセット後に再開 |
| Androidビルドや実機検証不可 | QA完了にしない。利用可能な環境・端末で検証するまで保留 |

停止報告には操作、理由、代替方法、保存場所、再開条件を含めます。
「続けて」という指示だけで有料実行を再開しません。
ホストが残量や請求経路を公開しない場合、ローカル検査だけで安全と断定しません。
