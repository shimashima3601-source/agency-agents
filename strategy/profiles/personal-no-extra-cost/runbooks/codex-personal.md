# 個人Codex Runbook

元の [NEXUS](../../../nexus-strategy.md) と
[引継ぎテンプレート](../../../coordination/handoff-templates.md) を参照します。
独自の無制限実行基盤に置き換えません。

1. **実行前**: profile・利用経路・請求設定・残量の確認。未知なら停止。
2. **Discovery**: 要求と手元資料を確認し、対象と成果物を決定。
3. **Strategy**: PMとArchitectが作業と受入条件を整理。サービス導入前に利用条件を確認。
4. **Foundation**: 契約内・ローカルで準備可能な環境だけを構築。
5. **Build**: 必要な開発役とQAを順次実行。1タスクにつき最大3回の総試行。
6. **Hardening**: 実際の検証結果と未検証範囲をReality Checkerが確認。
7. **Launch**: 対象サービス・費用を確認。未確認の公開・課金サービス導入は停止。
8. **Operate**: 根拠と状態を保存し、更新時の再検証とUpstream取り込みを行う。

元のFull / Sprint / Microの責務と品質ゲートを維持し、役割の必要性に応じて実行します。
本profileでは既定で順次実行とし、名簿にいる全Agentの常時起動を要求しません。
既存Runbookの名簿は変更しません。個人名簿は補助的な選択です。

上限・課金不明・ツール非対応時は成果物を保存し、未完了事項と再開条件を日本語で提示します。
利用できないQAを成功扱いせず、品質ゲートは未通過として保留します。
