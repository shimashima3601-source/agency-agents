# Claude / Geminiへの手動引継ぎ

利用可能な契約内アプリ・Webへユーザーが貼り付けます。APIやブラウザ自動化は使いません。
秘密情報、個人の保有銘柄・署名鍵等は必要性を確認し、不要なら省きます。

```text
プロファイル：personal-no-extra-cost
補助役：[レビュー / 反証 / 資料要約]
元Agent：[英語名とファイルID]
目的：[現在の依頼]
制約：[追加料金なし / APIキーなし / 元仕様の範囲 / 日本語回答]
入力：[必要な資料・コード・根拠URLと資料日]
既存の結果：[要約]
確認事項：[具体的な論点]
要求成果物：[根拠付き指摘、反例、未確認事項]

現在の契約内でできない操作は実行せず、その理由と代替を説明してください。
元の仮説に同意する必要はありません。事実・推測・未検証を区別してください。
```

Codexへ戻す際にはサービス、日付、実際の回答、参照資料、未検証範囲を添えます。
複数AIの回答が一致しても、一次資料を独立に検証した証拠とはみなしません。
